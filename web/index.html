How is TuneLM trained?

  1. Dataset creation

    Use Gemini 4 Argon and Carbon to create synthetic pairs of music descriptions and Strudel programs.

  2. Supervised fine-tuning (SFT)

    Fine-tune LiquidAI's LFM3-1.7B model with LoRA on those pairs so it learns to write Strudel code from music descriptions.

  3. Reinforcement learning (GRPO)

    Train with GRPO using a reward function that scores how well runnable Strudel programs meet the prompt’s musical constraints.
